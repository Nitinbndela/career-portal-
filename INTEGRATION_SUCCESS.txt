## 🚀 Quick Start

### Step 1: Install Dependencies
```bash
cd career-portal-
npm install
```

### Step 2: Run Everything
```bash
npm start
```

### Step 3: Open Browser
```
http://localhost:3000
```

**That's it!** The scraper is already running in the background.

## 📋 Key Settings

### Scrape Interval: 10 Minutes
Edit `src/services/scraper.js` line 15 to change:

```javascript
// Current (10 minutes):
scrapeInterval: 10 * 60 * 1000,

// Other options:
// 5 minutes:  5 * 60 * 1000
// 15 minutes: 15 * 60 * 1000
// 30 minutes: 30 * 60 * 1000
// 1 hour:     60 * 60 * 1000
```

### Data Location
Jobs are automatically saved and updated in:
```
src/data/jobs.json
```
